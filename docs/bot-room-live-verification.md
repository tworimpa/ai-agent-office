# 회의실 보행과 실제 봇 의뢰 검증

2026-11-26, 운영자가 허용한 일회용 Git 저장소에서 두 운영체제의 Studio HTTP API로 수행했다. 아래 실행은 읽기 전용 작업을 정상 완료한 `PLAN_ONLY`다. 엔진별로 직접 의뢰 한 건과 두 봇에게 분담한 왕명 한 건을 접수했다. 왕명은 해당 Workspace에 선택된 개발 엔진으로 각 봇의 실행을 생성한다.

Windows에서는 데스크톱과 같은 MXC 설정으로 앱 내장 Codex가 테스트 저장소의 임의 재고 코드와 수량을 읽어 순재고를 계산했다. Antigravity는 해당 봇에 고정된 자료에서 담당 행을 찾아 계산했다. 각 왕명의 두 봇은 서로 다른 자료를 받았다. 여섯 실행의 결과와 봇별 대화, Workspace 작업 기록을 Studio 재기동 뒤 다시 대조했다.

WSL Ubuntu에서는 Codex가 각 업무의 파일에서 서로 다른 임의 표식을 읽었다. 별도로 선택한 Linux Antigravity CLI는 세 산술 문제에 각각 2333, 1654, 2411을 답했다. 각 실행 ID에 사용자 발화와 봇 답변이 한 건씩 남고, 다른 봇의 대화에는 나타나지 않았다. Studio 재기동 후 같은 ID와 본문으로 다시 접수했을 때 최초 여섯 실행과 두 왕명이 유지됐다. 두 OS 모두 테스트 저장소의 원본 체크아웃이 깨끗했다.

보행 검증에는 공급자 로그인이 필요하지 않다. 실제 Edge에서 12개 WebP가 모두 로드되며 각 캐릭터의 위치와 보행 자세가 변하는지, 일시정지 시 위치가 유지되는지, 키보드로 봇 대화가 열리는지 확인했다. DOM 회귀 테스트는 중복 프리셋과 업로드 이미지의 이동, 네 방향 전환 및 책상 앞 마룻바닥 경계를 확인한다. 파일 수정·리뷰와 실제 공급자의 일반적인 신뢰성은 이 읽기 전용 검증의 범위 밖이다.
