# 안정 소스 버전 이력과 롤백 구현 계획

[4단계 제품 구상](../../product-vision.md)과 [기존 승격 절차](../../improvement-promotion.md)를 확장한다. 버전은 릴리스 저장소의 안정 소스 커밋이며, 실행 중인 서비스 배포는 별도 절차다.

1. 초기 버전, 승격, 롤백에 단조 증가 순번을 부여한다. 같은 트랜잭션에서 안정 포인터와 전환 이력을 갱신한다. 기존 릴리스는 초기 ref와 승인 결정 순서에서 이력을 복원하고 일치 여부를 검사한다.
2. 운영자 CLI가 현재 상태와 이전 안정 버전을 비교하고 전체 변경을 출력한다. 검토한 현재 순번·SHA와 대상 순번·SHA를 확인한 경우에만 롤백을 기록한다. 검토 중 상태가 바뀌면 결정을 중단한다.
3. 운영자가 선택한 조회 DB에 안정 버전 이력을 게시한다. 두 버전에서 변경된 파일을 비교하고 화면에 표시할 수 있는 본문과 범위를 명시한다. 작업실과 SSH 경로는 게시된 안정 버전만 조회한다.
4. 로컬·원격 호스트를 선택하는 버전 화면을 추가한다. 현재 버전, 승격·롤백 시각과 이동 방향, 선택한 두 버전의 차이를 보여준다. 사용자는 해당 운영자 터미널에서 롤백을 검토한다.
5. 이전 원장 호환, 중복·경합·중단, 거절된 후보 배제, 롤백 뒤 새 승격과 소스 추출, 게시와 재접속을 임시 Git·SQLite와 모의 작업으로 시험한다. Windows·Ubuntu CI와 병합 결과를 확인한다.
