## 시도 간 회귀와 프로세스 종료

별도의 설정 복원 fixture에서는 기준 커밋의 결함을 먼저 재현했다. 첫 후보는 저장된 값을 복원하는 빠른 검증을 통과했으나 새 설정 파일이 없는 경우의 전체 회귀에서 실패했다. 두 번째 후보는 빠른 검증과 전체 회귀를 모두 통과했다. 회귀 테스트는 각 시도의 변경을 다시 읽어 첫 번째 후보의 diff가 보존되는지, 직전 실패의 해소가 두 번째 결과에 남는지 확인한다. 기존 검사를 삭제·건너뛰거나 단언을 변경한 후보도 별도로 검사한다.

Windows 프로세스 검증은 실제 검사 프로세스에서 하위 프로세스를 만든 뒤 시간 제한과 소유자 연결 종료를 각각 발생시켰다. 프로세스 핸들로 하위 프로세스 종료를 확인했다. 출력 제한 테스트는 표준 출력과 표준 오류를 함께 발생시키고 마지막 출력과 원래 종료 코드 7이 보존되는지 확인했다. 관련 테스트는 `tests/test_goal_verification.py`와 `tests/test_goal_process.py`에 있다.
