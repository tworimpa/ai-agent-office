### 0.10.0의 변경 사항

- Workspace에서 조정자·개발자·리뷰어 봇을 배정할 수 있습니다. 조정자가 작업 순서와 완료 기준을 제안하며, 봇 회의실에서 멤버를 선택해 의뢰할 수 있습니다.
- 봇을 Bot Definition 1.0 기반 ZIP 공유 패키지로 내보내고 공개 Git 저장소에서 설치할 수 있습니다. 공유 ZIP에서는 개인 메모를 제외하고, 설치 기록에는 실제 커밋 SHA와 정의 해시를 남깁니다.
- 새 버전의 변경을 미리 보고 적용하거나, Git 연결 없이 업데이트 직전 상태로 한 단계 복원할 수 있습니다. 겹치지 않는 로컬 편집과 메모를 보존하고, 충돌하면 경로를 보여 주고 적용을 중단합니다.
- Studio의 봇 카탈로그에서 패키지를 검색하고 설치하거나 업데이트할 수 있습니다. 등록된 CODE-Skills 상세 링크는 브라우저에서 엽니다. 상세 링크 연결은 시험용 HTTPS 주소로 검증했습니다.

Windows와 WSL Ubuntu에서 Codex·Antigravity·Claude Code로 카탈로그 봇의 읽기 전용 실제 의뢰 6건을 완료했습니다. Gemini CLI·Cline의 실제 설치와 읽기 전용 검증은 사용 가능한 환경이 준비될 때까지 보류합니다. [검증 기록](https://github.com/tworimpa/ai-agent-office/issues/46)
